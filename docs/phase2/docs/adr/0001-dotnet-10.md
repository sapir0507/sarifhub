# 0001 — Target .NET 10 (LTS)

**Status:** Accepted (Phase 2)

**Context.** The project brief allowed .NET 8 or .NET 10. .NET 8 and .NET 9 both reach end of support on
10 November 2026; .NET 10 (released November 2025) is LTS and supported until November 2028.

**Decision.** Target `net10.0` for every project. Use EF Core 10 with the Npgsql provider.

**Consequences.** A portfolio project published in late 2026 would otherwise run on a runtime that stops receiving
security fixes within weeks — the wrong signal for a security product. .NET 10 also includes `Guid.CreateVersion7()`
(available since .NET 9), which the data model uses for time-ordered keys. Contributors need the .NET 10 SDK (Visual Studio 2026 or the CLI).
